# Экосистема продаж Olist: Сквозной бизнес-анализ маркетплейса

Commercial Data Analytics / Retail & E-Commerce

## Описание проекта
Этот проект посвящен анализу коммерческих показателей бразильского маркетплейса Olist. Здесь решаются три критические задачи бизнеса: оптимизация юнит-экономики, сегментация клиентов (RFM) и аудит логистических SLA.
